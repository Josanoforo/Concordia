# Concordia

Concordia discovers candidate relationships between registered data sources, checks them with bounded queries, and preserves decisions with evidence and provenance. The application combines deterministic validation, entity reconciliation, and report generation.

The repository contains the TypeScript application, automated tests, public configuration defaults, universe contracts, evaluation cases, and synthetic examples. Live runs require external Zetaris and Nightshift services. Credentials and run artifacts remain local.

The offline SAMPLE uses a synthetic schema graph with no source rows, key values, SQL, request IDs, or receipts. The public U3 schema and 30-row CSV examples are synthetic and contain no MaDI raw data or gold.
