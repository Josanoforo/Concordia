# Integrations demonstrated

The project focuses on the sponsor-relevant workflow of onboarding sources, building a USL, and explaining its limits.

| Component | Demonstrated use | Limit |
|---|---|---|
| Zetaris | Metadata discovery, bounded SQL probes, USL generation and activation for U1/U2, and a file-store path in the U3 evaluation work. | A bounded result is evidence about the returned rows, not global integrity. An expensive source read was excluded. U3 schema correspondence does not establish a foreign key. |
| Meterless / Nightshift | Optional model-assisted text generation through the runtime, with route receipts and a constrained provider policy. | A selected route or cached result is not a new generation. Model output cannot change mechanical verdicts or SQL. |
| H-MEM | Reconciliation preserves claims, alternatives, corrections, provenance, and ledger history; the upstream conformance suite is retained. | Concordia's adapter behavior is distinct from the upstream component. |
| NVIDIA / Nemotron | Not used by this project. | No claim is made about model use or performance. |

The USL is evaluated as an explicit, inspectable model. Confidence scores summarize bounded evidence; they are not calibrated probabilities or guarantees over full source tables.
