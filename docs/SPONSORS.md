# Integrations demonstrated

The project focuses on the sponsor-relevant workflow of onboarding sources, building a USL, and explaining its limits.

| Component | Demonstrated use | Limit |
|---|---|---|
| Zetaris | Metadata discovery, bounded SQL probes, USL generation and activation for U1/U2, and a file-store path in the U3 evaluation work. A USL plan originated by the agent (`agent-usl-plan`) for one GTFS relation on an imported subset was applied live into a new dated namespace and verified: 3 DDL/activation statements and 25 reads, with no model calls. | A bounded result is evidence about the returned rows, not global integrity. An expensive source read was excluded. U3 schema correspondence does not establish a foreign key. The applied GTFS relation is sustained on a bounded sample only, with no uniqueness or global coverage claim, and still requires review. |
| Meterless — H-MEM Engine (required Build integration) | Concordia's reconciliation memory. Claims, alternatives, corrections, human reviews, provenance and ledger history are stored as H-MEM records. The upstream H-MEM conformance suite passed 13/13 against Concordia's implementation (`src/hmem`). With `--memory`, the agent loop writes its relation claims with run-id provenance into this memory and reuses relations sustained in earlier runs. This was exercised offline and in one live two-pass run on `GTFSAGENT`, where the second pass reused the first pass's sustained claim. | Concordia's adapter behavior (`src/reconcile`: typed claims, same-entity conflicts, review) is distinct from the upstream component. The upstream files are vendored with one added method (`restoreAll` in `src/hmem/trustLedger.ts`); all other files are identical to upstream revision `1742dec` (see [PREEXISTING.md](PREEXISTING.md) and `src/hmem/NOTICE`). |
| Meterless — Nightshift (required Power integration) | Concordia's only AI provider. Every model call goes through the Meterless Runtime (requested route `meterless/cheap`) and is recorded with a receipt before its result is used. Recorded runs include a connectivity check and the U1 live walkthrough (observed Anthropic claude-sonnet-5). In the bounded U2 agent run `agent-u2-adaptive-20261024-normal-03`, the planner's decisions were six receipted Nightshift calls. | Model output proposes candidates and explains fixed verdicts. It cannot change mechanical verdicts or SQL. A selected route or cached result is not a new generation. These are bounded runs, not a global routing claim. |
| NVIDIA / Nemotron | Not used by this project. | No claim is made about model use or performance. |

The USL is evaluated as an explicit, inspectable model. Confidence scores summarize bounded evidence; they are not calibrated probabilities or guarantees over full source tables.
