# U2 — USL summary (redacted)

This public summary omits company identifiers, row values, request identifiers, source paths, and per-run traces. The complete original dossier is preserved outside the public repository.

The U2 model contains two supported relationships: one between normalized company identifiers and one between company classification codes and their reference schema. A separate literal-equality case missed the one observed sample match; the bounded comparison did not attribute that record to another company. This demonstrates a normalization issue for that sample, not a population-wide error rate.

Normalization must be explicit and lossless at both ends. A relation supported by a bounded sample is not proof of global uniqueness, completeness, or entity identity. The public synthetic fixtures are separate from this historical observation and are not presented as its evidence.
