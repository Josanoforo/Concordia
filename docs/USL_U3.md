# U3 — schema-matching summary

U3 is evaluated as schema matching, not as a deployed USL or a set of foreign keys. Correspondence between column meanings is weaker than evidence that rows identify the same entity.

The public U3 input and schema files are explicitly synthetic fixtures. They are not MaDI source records, benchmark outputs, or gold labels. No raw benchmark data or gold file is included. Any local benchmark result must be interpreted under the individual licenses of its source datasets.
